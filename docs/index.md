## សេចក្ដីផ្ដើម

LEE RS Lab ជាកម្មវិធីជំនួយ (plugin) QGIS សម្រាប់ការចាប់សញ្ញាពីចម្ងាយ ដែលដំណើរការលើកុំព្យូទ័ររបស់អ្នកផ្ទាល់ ដោយមិនចាំបាច់មានគណនី ឬចូល (login) ទេ។ LEE មកពី **Local Earth Engine** — គណនាបែប Google Earth Engine ប៉ុន្តែនៅលើម៉ាស៊ីនរបស់អ្នក ជាមួយទិន្នន័យឥតគិតថ្លៃពី Microsoft Planetary Computer និង Earth Search (AWS)។

សៀវភៅណែនាំនេះប្រើឧទាហរណ៍ពិតមួយ៖ **ឃុំមហាខ្ញូង ស្រុកកោះសូទិន ខេត្តកំពង់ចាម** (23.7 គ.ម²) នៅមាត់ទន្លេមេគង្គ ជាមួយរូបភាព Landsat 9 រដូវប្រាំង ឆ្នាំ 2026។

### អ្វីដែលត្រូវមាន

- QGIS 3.22 ឬថ្មីជាងនេះ (រូបថតក្នុងសៀវភៅនេះប្រើ QGIS 3.44 លើ macOS)
- អ៊ីនធឺណិត ដើម្បីទាញយករូបភាព និងព្រំដែនរដ្ឋបាល
- ឯកសារ `lee_rs_lab.zip`

### ការដំឡើង

1. បើក QGIS → **Plugins › Manage and Install Plugins…**
2. ជ្រើស **Install from ZIP** រួចជ្រើសឯកសារ `lee_rs_lab.zip` → **Install Plugin**។
3. រូបតំណាង LEE RS Lab លេចឡើងលើរបារឧបករណ៍។ ចុចវាដើម្បីបើកផ្ទាំង។ ចុចម្ដងទៀត (ពេលផ្ទាំងនៅខាងមុខ) ដើម្បីបិទ។

### ផ្ទាំងបញ្ជា

ផ្នែកខាងលើនៃផ្ទាំងមាន៖ ការជ្រើសភាសា **English / ខ្មែរ (Khmer)**, ប៊ូតុងផែនទីមូលដ្ឋាន (Google Satellite, Esri, OSM…), ប៊ូតុង **ជំនួយ** និង **PDF** (របាយការណ៍)។ បន្ទាត់ខាងក្រោមបង្ហាញស្ថានភាព ឬសារចុងក្រោយ។

ការងារត្រូវបានចែកជា ៥ ផ្ទាំង។ ផ្ទាំងនីមួយៗមានផ្នែកបត់បាន ដែលបើកម្ដងមួយ៖

| ផ្ទាំង | ផ្នែក |
| --- | --- |
| 1 ទិន្នន័យ | តំបន់សិក្សា · រូបភាព — ស្វែងរករូបភាព · ផ្សំរូបភាព និងទាញយក · សំណុំទិន្នន័យផ្សេងទៀត · ការរៀបចំ |
| 2 កែលម្អ | បន្សំប៊ែន និងការលាតពន្លឺ · សន្ទស្សន៍វិសាលគម · តម្រងលំហ · PCA |
| 3 ចាត់ថ្នាក់ | ថ្នាក់ (តារាងសម្គាល់) · មិនណែនាំ · មានណែនាំ · ភាពត្រឹមត្រូវ · សម្អាត និងនាំចេញជាពហុកោណ · ប្លង់ផែនទី |
| 4 ការប្រែប្រួល | ពី → ទៅ · ការដករូបភាព · ដ្យាក្រាម Sankey |
| 5 LEE | ស្គ្រីបបែប Earth Engine ៣២ ឧទាហរណ៍ |

ផ្នែកនីមួយៗមានប៊ូតុង **📖 មេរៀន** ដែលពន្យល់ទ្រឹស្ដីខ្លីៗ។ ប្រើវាពេលបង្រៀនក្នុងថ្នាក់។

លំហូរការងារធម្មតា៖ **កំណត់តំបន់សិក្សា → ទាញយករូបភាព → កែលម្អ និងគណនាសន្ទស្សន៍ → ចាត់ថ្នាក់ → វាយតម្លៃភាពត្រឹមត្រូវ → រកការប្រែប្រួល**។

> **របៀបអានរូបភាពក្នុងសៀវភៅនេះ៖** រង្វង់ក្រហមមានលេខ ❶ ❷ ❸ … = លេខជំហានក្នុងអត្ថបទ ហើយប្រអប់ក្រហមបង្ហាញកន្លែងត្រូវចុច ឬកំណត់។ ប្រអប់ពណ៌លឿង = កន្លែងមើលលទ្ធផល។ ចុចលើរូបដើម្បីពង្រីក។
